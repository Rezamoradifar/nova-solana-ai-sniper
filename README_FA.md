# Nova Solana AI Sniper

**یک پلتفرم معاملاتی سولانا مبتنی بر هوش مصنوعی و درجه نهادی** — شناسایی
بلادرنگ عرضه توکن در چندین منبع کشف، تحلیل ریسک آنچین، امتیازدهی به‌کمک
مدل‌های زبانی، اجرای خودکار خرید/فروش در چندین صرافی غیرمتمرکز (DEX)،
یک سیستم کیف‌پول داخلی امانی با دفترکل غیرقابل‌تغییر، توزیع سود، برنامه
ریفرال چندسطحی، یک موتور برداشت وجه بازبینی‌شده، مجموعه‌ای از ربات‌های
تلگرام، و یک داشبورد React.

نسخه انگلیسی: [README.md](./README.md)

## نمای کلی پروژه

Nova Solana AI Sniper توکن‌های تازه‌عرضه‌شده و پرطرفدار سولانا را در
چندین منبع کشف مستقل شناسایی می‌کند، هر یک را با یک موتور ریسک قطعی
مبتنی بر قاعده به‌همراه یک نظر دومِ اختیاری از مدل زبانی امتیازدهی
می‌کند، و — وقتی یک توکن از تمام گیت‌های ایمنی عبور کند — به‌نمایندگی از
هر کاربری که پیکربندی اسنایپ او مطابقت داشته باشد، یک خرید خودکار انجام
می‌دهد. پوزیشن‌های باز به‌طور مداوم برای take-profit، stop-loss، تریلینگ
استاپ، خروج اضطراری، و (در «حالت نهادی») یک نردبان خروج جزئی سود
پایش می‌شوند. هر معامله، واریز، برداشت، سهم سود، و پاداش ریفرال در یک
دفترکل و مسیر ممیزی غیرقابل‌تغییر ثبت می‌شود. کاربران از طریق ربات
تلگرام یا داشبورد وب تعامل می‌کنند؛ وجوه در کیف‌پول‌های امانی جداگانه و
رمزنگاری‌شده هر کاربر نگهداری می‌شوند — هیچ خزانه‌داری استخری وجود ندارد.

هدف رقابتی از نظر مجموعه ویژگی‌ها: BullX، Photon، Maestro، Banana Gun،
Trojan، BonkBot.

## ویژگی‌ها

- **کشف چندمنبعی** — اشتراک لاگ برنامه آنچین در pump.fun / PumpSwap /
  Raydium (AMM و CLMM) / Orca Whirlpool / Meteora DLMM / OpenBook v2 /
  Moonshot / Phoenix / Fluxbeam، به‌همراه نظرسنجی‌کننده‌های
  boosted/profile در DexScreener، یک نظرسنجی‌کننده Birdeye، یک مانیتور
  اشاره در ایکس (توییتر)، و یک مانیتور کانال ترند تلگرام — هرکدام
  به‌طور مستقل قابل فعال/غیرفعال‌سازی.
- **امتیازدهی دو‌لایه ریسک و هوش مصنوعی** — یک موتور امتیازدهی قطعی و
  کاملاً مبتنی بر قاعده (اختیار mint/freeze، قفل/سوزاندن نقدینگی،
  پراکندگی هولدرها، عمق نقدینگی، اکتشافات هانی‌پات) که همیشه اجرا
  می‌شود، به‌همراه یک نظر دومِ اختیاری از Claude/OpenAI که امتیاز آن فقط
  می‌تواند توسط سقف قطعی _کاهش_ یابد، هرگز رو به بالا override نمی‌شود.
- **اجرای خودکار** — Jupiter aggregator به‌عنوان مسیر اصلی، با یک اجرای
  بومی جایگزین برای هر DEX زمانی که Jupiter نتواند سواپ را مسیریابی کند؛
  هر پرشدگی در برابر تغییر واقعی موجودی آنچین تأیید می‌شود، هرگز صرفاً
  بر پایه نقل‌قول.
- **استراتژی‌های خروج** — take-profit/stop-loss ثابت، یک تریلینگ استاپ
  تطبیقی، نردبان سود «حالت نهادی» (خروج جزئی در سطوح سود قابل‌تنظیم با
  یک ذخیره «moonbag» محافظت‌شده)، و یک موتور خروج اضطراری که مستقل از
  قیمت بر اساس سیگنال‌های راگ/دامپ (نقدینگی خارج‌شده، فعال‌سازی مجدد
  اختیارات، دامپ کیف‌پول توسعه‌دهنده) نقدشوندگی اجباری انجام می‌دهد.
- **کیف‌پول داخلی و دفترکل غیرقابل‌تغییر** — هر کاربر یک کیف‌پول سولانای
  جداگانه رمزنگاری‌شده (AES-256-GCM) دریافت می‌کند؛ هر رویداد
  اثرگذار بر موجودی (واریز، برداشت، اعتبار سود، کارمزد پلتفرم، پاداش
  ریفرال) به‌صورت یک جفت `LedgerEntry` + `AuditLog` غیرقابل‌تغییر ثبت
  می‌شود که در سطح پایگاه‌داده توسط یک تریگر، نه صرفاً منطق برنامه،
  غیرقابل‌تغییر بودنش تضمین شده است.
- **توزیع سود** — یک سیستم کارمزد عملکرد، سود تحقق‌یافته را بین
  معامله‌گر، پلتفرم، و زنجیره ریفرال تقسیم می‌کند، با یک جاروب تطبیق که
  حتی در برابر کرش پردازه یا رویداد ازدست‌رفته، سازگاری نهایی را تضمین
  می‌کند.
- **برنامه ریفرال چندسطحی** — تا یک عمق قابل‌تنظیم، با فعال‌سازی خودکار
  پاداش پس از عبور معرف از یک آستانه، و یک جدول امتیازات کامل ریفرال.
- **موتور برداشت وجه بازبینی‌شده** — خط لوله درخواست → امتیاز ریسک →
  بازبینی ادمین → تأیید → اجرای آنچین → تطبیق، با محافظت در برابر
  درخواست تکراری، محدودیت‌های روزانه/حداقل/حداکثر، و چک‌پوینت‌های اجرای
  مقاوم در برابر کرش.
- **مجموعه ربات تلگرام** — هشدارهای معاملاتی، مدیریت کیف‌پول، پیکربندی
  اسنایپ، داشبورد ریفرال/درآمد، درخواست‌های برداشت، و یک سطح کنترل ادمین
  (کلید قطع اضطراری، توقف/ازسرگیری، تنظیمات کارمزد/ریفرال).
- **داشبورد وب** — پوزیشن‌های زنده، تحلیل پرتفوی، تاریخچه کیف‌پول و
  تراکنش، نمای ریفرال و توزیع سود، درخواست‌های برداشت و صف تأیید ادمین،
  جدول امتیازات PnL، و یک فید زنده توکن — با نظرسنجی REST به‌همراه یک
  پوش رویداد WebSocket به‌روز می‌شود.

## نصب

برای دستورالعمل کامل راه‌اندازی (توسعه محلی، Docker Compose، و استقرار
تولید بدون‌داکر/PM2) به `INSTALL.md` مراجعه کنید.

شروع سریع:

```bash
npm install
cp .env.example .env   # مقادیر محرمانه را پر کنید — به بخش متغیرهای محیطی مراجعه کنید
npm run prisma:migrate
npm run dev:api
```

## پیکربندی

تمام پیکربندی از طریق متغیر محیطی انجام می‌شود (`packages/shared/src/
env.ts` منبع حقیقت واحد است که در زمان بوت با `zod` اعتبارسنجی می‌شود).
برای فهرست کامل و مستندشده به `.env.example` مراجعه کنید. فقط
`DATABASE_URL`، `REDIS_URL`، `JWT_SECRET`، و `ENCRYPTION_KEY` برای بوت
API الزامی هستند — سایر یکپارچه‌سازی‌ها (ارائه‌دهندگان RPC سولانا،
Helius، Jito، Anthropic/OpenAI، تلگرام، توییتر، Birdeye) اختیاری‌اند و
ویژگی مربوطه به‌جای کرش، با یک لاگ هشدار غیرفعال می‌شود.

## اجرا

```bash
npm run dev:api          # API فستیفای + workerهای پس‌زمینه کشف/معاملات
npm run dev:bot           # ربات تلگرام
npm run dev:marketing     # موتور محتوای بازاریابی هوش مصنوعی
npm run dev:dashboard     # داشبورد React (سرور توسعه Vite)

npm run build              # ساخت تمام workspaceها
npm run test                # اجرای کل مجموعه تست (Vitest)
npm run lint / lint:fix
npm run typecheck
```

نظارت پردازه تولید از طریق PM2 (`ecosystem.config.cjs`) در استقرارهای
بدون‌داکر/VPS، یا `restart: unless-stopped` + healthcheck خود Docker
Compose در مسیر کانتینری است — برای هر دو به `INSTALL.md` مراجعه کنید.

## متغیرهای محیطی

مرجع کامل: `.env.example`.

| گروه          | نمونه‌ها                                                                                                                                                                                                              |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| زیرساخت اصلی  | `DATABASE_URL`, `REDIS_URL`, `API_PORT`, `API_HOST`, `CORS_ORIGIN`                                                                                                                                                    |
| کلیدهای ایمنی | `LIVE_TRADING`, `KILL_SWITCH`, `MAX_TRADE_SOL`, `MAX_DAILY_LOSS_USD`, `MAX_OPEN_POSITIONS`, `MIN_WALLET_RESERVE_SOL`                                                                                                  |
| محرمانه‌ها    | `JWT_SECRET`, `ENCRYPTION_KEY`                                                                                                                                                                                        |
| RPC سولانا    | `SOLANA_RPC_URL`, `SOLANA_WS_URL`, `HELIUS_API_KEY`, `QUICKNODE_RPC_URL`, `CHAINSTACK_RPC_URL`, `JITO_BLOCK_ENGINE_URL`                                                                                               |
| هوش مصنوعی    | `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`                                                                                                                                                                                 |
| منابع کشف     | `RAYDIUM_CLMM_SOURCE_ENABLED`, `OPENBOOK_SOURCE_ENABLED`, `MOONSHOT_SOURCE_ENABLED`, `PHOENIX_SOURCE_ENABLED`, `LIFINITY_SOURCE_ENABLED`, `FLUXBEAM_SOURCE_ENABLED`, `DEXSCREENER_*`, `BIRDEYE_*`, `TELEGRAM_TREND_*` |
| تلگرام        | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`                                                                                                                                                                              |
| برداشت وجه    | `WITHDRAWAL_EXECUTION_ENABLED`, `WITHDRAWAL_EXECUTION_INTERVAL_MS`                                                                                                                                                    |
| واریز         | `DEPOSIT_MONITOR_ENABLED`, `DEPOSIT_MONITOR_INTERVAL_MS`                                                                                                                                                              |

**هرگز `.env` را کامیت نکنید.** کلیدهای خصوصی کیف‌پول با استفاده از
`ENCRYPTION_KEY` رمزنگاری‌شده (AES-256-GCM) در حالت سکون نگهداری می‌شوند
و هرگز به‌صورت متن ساده لاگ یا از API بازگردانده نمی‌شوند.

## API

مرجع کامل: `API.md`. REST، احراز هویت با JWT bearer، ورودی/خروجی JSON،
اعتبارسنجی بدنه درخواست با Zod، محدودسازی نرخ چندلایه.

## داشبورد

SPA مبتنی بر React/Vite که پشت Nginx اجرا می‌شود. صفحات: نمای کلی،
توکن‌ها، پوزیشن‌ها، پرتفوی، کیف‌پول‌ها (+ جزئیات هر کیف‌پول)، ریفرال،
توزیع سود، برداشت‌ها (+ صف تأیید ادمین)، پیکربندی‌های اسنایپ، جدول
امتیازات، و لاگ‌ها.

## ربات تلگرام

ساخته‌شده روی `grammy`. دستورات کاربری شامل `/start`، `/withdraw`،
`/withdrawals`، `/withdrawstatus`، `/profits`، `/earnings`، `/fees`،
`/distribution`، به‌همراه صفحات گسترده مبتنی بر کیبورد این‌لاین برای
مدیریت کیف‌پول، پیکربندی اسنایپ/استراتژی خروج، پایش زنده پوزیشن، و
ریفرال. دستورات مختص ادمین: `/status`، `/stats`، `/pauseall`،
`/resumeall`، `/killswitch`، `/setfee`، `/setreferral`،
`/setreferraldepth`، `/togglereferral`، `/businessreport`.

## کیف‌پول

هر کاربر یک کیف‌پول سولانای جداگانه تولیدشده (mnemonic استاندارد
BIP39) دریافت می‌کند. کلید خصوصی با AES-256-GCM رمزنگاری‌شده و **هیچ
کیف‌پول خزانه‌داری استخری در این کدبیس وجود ندارد** — معاملات و برداشت‌ها
همیشه مستقیماً به/از کیف‌پول خود کاربر منتقل می‌شوند.

## ریفرال

هر کاربر در ثبت‌نام یک کد ریفرال منحصربه‌فرد دریافت می‌کند. هنگامی که یک
معامله با سود بسته می‌شود، کارمزد عملکرد در سراسر زنجیره ریفرال بر اساس
درصد قابل‌تنظیم هر سطح تقسیم می‌شود. معرفی ۳ کاربر، یک پیکربندی اسنایپ
پیش‌فرض خودکار را برای معرف باز می‌کند که دقیقاً یک‌بار از طریق یک
محدودیت یکتای پایگاه‌داده اعطا می‌شود.

## توزیع سود

یک موتور رویدادمحور (مشترک مسیر سریع + جاروب تطبیق دوره‌ای) هر ردیف
دفترکل کارمزد عملکرد از پیش محاسبه‌شده یک پوزیشن بسته‌شده سودآور را به
یک رکورد دائمی `ProfitDistribution` تبدیل می‌کند — کاملاً ایدمپوتنت از
طریق محدودیت‌های یکتای پایگاه‌داده.

## برداشت وجه

درخواست → امتیازدهی خودکار ریسک → (اختیاری) بازبینی ادمین → تأیید →
انتقال واقعی SOL آنچین → تطبیق. حفاظت‌ها شامل: یک رزرو موجودی به‌روزرسانی
شرطی اتمی، یک ایندکس یکتای جزئی پایگاه‌داده که کاربر را به یک درخواست
فعال محدود می‌کند، کلیدهای ایدمپوتنسی اختیاری، قفل ردیف `SELECT ... FOR
UPDATE` در هر انتقال وضعیت، و یک چک‌پوینت ایمن در برابر کرش که امضای
تراکنش را همان لحظه پخش، پیش از تأیید، به‌طور پایدار ثبت می‌کند.

## امنیت

مرجع کامل: `SECURITY.md`. نکات برجسته: رمزنگاری کلید در حالت سکون با
AES-256-GCM، هش رمز عبور با scrypt و مقایسه `timingSafeEqual`، احراز
هویت JWT با محدودسازی نرخ چندلایه، اعتبارسنجی Zod روی هر ورودی، بررسی
مالکیت در هر مسیر مختص کاربر، مسیر دفترکل/ممیزی غیرقابل‌تغییر (تضمین‌شده
با تریگر)، و فهرست بازبینی‌شده و مستندشده یافته‌های پذیرفته‌شده
`npm audit` به‌جای یک force-fix کورکورانه.

## تست

```bash
npm run test        # Vitest — ۹۹۷ تست در کل workspaceها
npm run typecheck    # tsc --noEmit، هر workspace
```

assertionهای مسیر شادِ (happy-path) معمول.
