# Telegram Bot Screenshots

This folder is reserved for real screenshots of the Telegram bot's
inline-keyboard screens (wallet management, snipe/exit-strategy
configuration, position monitoring, referrals, withdrawals, admin
controls).

None are included yet. The Telegram bot's UI is not a web page — it cannot
be captured by headless-browser automation the way the dashboard can, and
this documentation pass did not open a live Telegram session against the
bot. Rather than fabricate a mockup and label it as a real screenshot, this
folder is left for a maintainer to populate from an actual Telegram client.

**To add these:** open a chat with the bot (`TELEGRAM_BOT_TOKEN`'s
associated bot) from a real Telegram client, run `/start` and the commands
listed in `README.md`'s "Telegram Bot" section, and save screenshots of the
resulting screens.
