# Dashboard Screenshots

This folder is reserved for real screenshots of the live dashboard
(Overview, Tokens, Positions, Portfolio, Wallets, Referral, Profit
Distribution, Withdrawals, Snipe Configs, Leaderboard, Logs).

None are included yet. Capturing them requires authenticating as a real
user against the running application, and this documentation pass was
explicitly scoped as **documentation only — no database writes** (no demo
account was created, and none was fabricated as a substitute). Rather than
ship a staged or synthetic image labeled as a product screenshot, this
folder is left for a maintainer with an authorized account to populate.

**To add these:** log into the dashboard with a real account, navigate to
each route listed in `README.md`'s "Dashboard" section, and save a
screenshot named after the route (e.g. `positions.png`, `portfolio.png`,
`wallets.png`).
