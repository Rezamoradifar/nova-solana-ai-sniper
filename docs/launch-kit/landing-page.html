What's actually built

Every claim below maps to a running system, not a roadmap slide.

Multi-source discovery

pump.fun, PumpSwap, Raydium, Orca, Meteora, OpenBook v2, Moonshot, Phoenix, Fluxbeam — plus DexScreener, Birdeye, X, and Telegram trend signals. One source failing never stops the rest.

Two-layer risk & AI scoring

A deterministic engine runs on every token, unconditionally. An optional AI opinion can only lower the score — never raise it — and fails closed on timeout.

Verified execution

Jupiter aggregator as primary route, native per-DEX fallback, every fill checked against the real on-chain balance delta.

Configurable exits

Fixed take-profit/stop-loss, adaptive trailing stop, an optional partial-exit ladder, and a price-independent Emergency Exit Engine.

Immutable ledger

Every deposit, withdrawal, fee, and referral reward is a database-enforced, append-only record — not just application-level bookkeeping.

Reviewed withdrawals

Request → automated risk score → admin review → on-chain execution → reconciliation, with duplicate-request protection and daily limits.

Your wallet. Not a pool.

Every user gets an individually AES-256-GCM-encrypted Solana wallet at signup. Funds are never commingled with any other user's funds — there is no shared treasury.

This is still a custodial model: the platform holds your encrypted key so it can trade on your behalf. Read the risk disclosure below before depositing.
