# اتصال کیف پول و زبان مشترک مانی‌لند

در نسخهٔ قبلی، صفحهٔ اصلی و ترمینال پنجره‌های اتصال جدا داشتند و صفحات عمومی زبان مشترک نداشتند. این نسخه یک پنجرهٔ اتصال و یک انتخاب فارسی/انگلیسی را در سطح برنامه نگه می‌دارد. جابه‌جایی بین صفحهٔ اصلی، بازارها، کپی‌ترید، کیف پول، ترمینال و حساب، اتصال تأییدشده را از بین نمی‌برد.

## اتصال

- الگوی پروژهٔ Smart Contract Platform در مخزن `Rezamoradifar/dravon` بررسی شده است: آن پروژه از RainbowKit/Wagmi و WalletConnect برای شبکهٔ EVM استفاده می‌کند. پیاده‌سازی نوا از Reown AppKit Core و WalletConnect Universal Provider سازگار با سولانا استفاده می‌کند.
- Phantom، Solflare و SafePal شناسایی‌شده در مرورگر همچنان از مسیر Wallet Standard متصل می‌شوند. گزینهٔ WalletConnect برای کیف پول‌های سازگار، QR و انتخاب کیف پول موبایل را باز می‌کند.
- بارگذاری SDK و اتصال به relay فقط پس از انتخاب WalletConnect انجام می‌شود. در نبود تنظیمات Reown، مسیر افزونه‌ها و مرورگر داخل کیف پول باقی می‌ماند و QR فعال معرفی نمی‌شود.
- فقط حساب تأییدشدهٔ شبکهٔ اصلی سولانا پذیرفته می‌شود. این اتصال هیچ متد امضای پیام، تراکنش یا ارسال معامله‌ای به رابط برنامه اضافه نمی‌کند. کیف پول سایت، ورود حساب و کیف پول‌های معاملاتی سرور اختیارهای مستقل دارند.
- لغو درخواست، رد تأیید، تغییر حساب و پایان نشست بررسی شده‌اند. تأیید دیرهنگام یک درخواست لغوشده، اتصال سایت را دوباره فعال نمی‌کند.

## تنظیم موردنیاز برای QR

یک Project ID واقعی از [داشبورد Reown](https://cloud.reown.com) لازم است. این مقدار شناسهٔ عمومی برنامه است؛ کلید RPC، توکن ربات یا عبارت بازیابی نیست. دامنهٔ `https://moneyland.tr` و در صورت استفاده `https://www.moneyland.tr` را در فهرست مجاز پروژهٔ Reown قرار دهید.

تنظیم ساخت وب `VITE_WALLETCONNECT_PROJECT_ID` است. نصب‌کننده مقدار را در ترمینال می‌پرسد؛ برای به‌روزرسانی‌های بعدی، شناسهٔ عمومی ثبت‌شده روی تصویر نصب‌شده را دوباره استفاده می‌کند. شناسهٔ تست CI روی سرور نصب نمی‌شود.

## فارسی و انگلیسی

- انتخاب زبان از `moneyland-language` خوانده و ذخیره می‌شود. پارامتر مجاز `?lang=fa` یا `?lang=en` برای انتقال انتخاب به مرورگر کیف پول موبایل پشتیبانی می‌شود؛ پارامترهای دیگر صفحه، توکن یا fragment به لینک موبایل منتقل نمی‌شوند.
- `lang` و `dir` سند در سطح برنامه تنظیم می‌شوند. تغییر بخش سایت، زبان یا جهت صفحه را بازنشانی نمی‌کند. تب‌های باز نیز انتخاب جدید را دریافت می‌کنند.
- منو، صفحه‌های عمومی، فرم ورود و بخش‌های اصلی حساب از ترجمهٔ مشترک استفاده می‌کنند. نام کیف پول کاربر، آدرس‌ها، نماد توکن، دادهٔ سرویس‌های بیرونی و شناسه‌های مالی و فنی ترجمه نمی‌شوند.
- ورود از یک ابزار به همان مقصد محلی برمی‌گردد. مقصد خارجی، API و مینی‌اپ برای بازگشت ورود پذیرفته نمی‌شوند.

## نصب روی سرور موجود

فقط از SHA کامل نسخهٔ بررسی‌شده استفاده کنید. دستور پین‌شدهٔ همان نسخه در پاسخ نصب ارائه می‌شود. نصب‌کننده و فایل کمکی `disable-telegram-miniapp.py` باید از همان SHA و در یک پوشه استخراج شوند. فایل کمکی فقط برای بررسی کانتینرها و لایه‌های Compose وارد می‌شود؛ عملیات خاموش‌سازی یا تغییر منوی تلگرام اجرا نمی‌شود.

`deploy-nova-wallet-language.py --app-dir /opt/nova-solana-ai-sniper --release <reviewed-40-character-SHA>` را از ترمینال root اجرا کنید. در نبود تنظیم ذخیره‌شده، Project ID عمومی را می‌پرسد. آدرس پیش‌فرض بررسی `https://moneyland.tr` است.

نصب‌کننده:

1. پیکربندی Compose را با hash کانتینر فعلی مطابقت می‌دهد و لایه‌های موجود را فقط در صورت تغییر تصویر می‌پذیرد.
2. سلامت وب و API و پاسخ ۴۱۰ بدون کش مینی‌اپ را پیش از تغییر بررسی می‌کند.
3. منبع دقیق commit را جدا استخراج و تصویر وب را با شناسهٔ عمومی واقعی می‌سازد. checkout و `.env` و فایل‌های nginx را بازنویسی نمی‌کند.
4. تصویر قبلی را نگه می‌دارد و فقط `gsp-web` را با تصویر جدید جایگزین می‌کند. API، پایگاه داده، ربات، پردازشگرها و تنظیمات معامله بازسازی نمی‌شوند.
5. manifest نسخه و فایل ورودی جاوااسکریپت را از دامنهٔ عمومی بررسی می‌کند. شناسهٔ کانتینرهای دیگر و فایل‌های تنظیمات باید ثابت بمانند. شکست بررسی باعث بازگردانی تصویر قبلی وب می‌شود.

نشانه‌های موفقیت: `NOVA_WALLET_UI_UPDATED=YES` و `WALLETCONNECT_CONFIGURED=YES` و `MINIAPP_DISABLED=YES`. این نتیجه، تأیید کیف پول واقعی یا انجام معامله را اثبات نمی‌کند؛ تأیید اتصال در دستگاه کاربر لازم است.

مسیر پشتیبان خصوصی و دستور دقیق restore چاپ می‌شود. فایل‌های استخراج‌شده و تصویر قبلی را نگه دارید. restore روی یک استقرار جدیدتر وب بازنویسی انجام نمی‌دهد. این نصب، حالت PAPER، توقف اضطراری، RPC یا سقف معاملات را تغییر نمی‌دهد.

## اعتبارسنجی

تست‌های مرز SDK، حساب سولانا، لغو و تأیید دیرهنگام، زبان و مسیر بازگشت ورود، لینک موبایل و رگرسیون کپی‌ترید همراه با TypeScript و ساخت تولیدی اجرا می‌شوند. تست مرورگر با حساب ساختگی، Chrome دسکتاپ/اندروید و WebKit آیفون را پوشش می‌دهد؛ کلید خصوصی یا کیف پول واقعی در تست‌ها استفاده نمی‌شود. CI تصویر واقعی Docker و manifest نسخه را هم می‌سازد و بررسی می‌کند.

مرجع پیاده‌سازی: [AppKit Core / Universal Provider](https://docs.reown.com/appkit/upgrade/wcm)، [Universal Provider](https://docs.reown.com/advanced/providers/universal)، [Compose config](https://docs.docker.com/reference/cli/docker/compose/config/).
