# مانی‌لند: طراحی لوکس و اتصال تأییدشدهٔ سولانا

صفحهٔ اصلی با پس‌زمینهٔ ابسیدین، طلایی شامپاینی، نشان سه‌بعدی سولانا و فونت گیمینگ Oxanium بازطراحی شده است. فونت فارسی Vazirmatn و فونت اعداد JetBrains Mono هستند. فونت‌ها روی خود سایت میزبانی می‌شوند؛ ظاهر مشترک به صفحه‌های عمومی، ترمینال، حساب و پنجرهٔ کیف پول می‌رسد. زبان فارسی/انگلیسی و اتصال تأییدشده در جابه‌جایی بین صفحات حفظ می‌شوند.

## داده و شبکه

- `/api/public/solana/overview` از یک endpoint مشخص، Genesis Hash، اسلات تأییدشده، نمونهٔ تراکنش بدون رأی و وضعیت حساب برنامه‌ها را می‌خواند. شناسه باید با `5eykt4UsFv8P8NJdTREpY1vzqKqZKvdpKuc147dw2N9d` مطابقت داشته باشد. دادهٔ شبکهٔ دیگر پذیرفته نمی‌شود.
- هویت زنجیره و داده در همان batch و همان endpoint خوانده می‌شوند؛ failover این داده‌ها را از چند provider با هم ترکیب نمی‌کند. نشانی خصوصی provider و خطای خام آن به مرورگر برنمی‌گردند.
- درخواست‌های هم‌زمان نمای کلی ادغام و پاسخ موفق تا ۱۵ ثانیه با زمان مشاهدهٔ اصلی نگه‌داری می‌شود. مرورگر شواهد قدیمی‌تر از ۴۵ ثانیه را تأییدشده نشان نمی‌دهد. شکست بررسی، باعث جایگزینی قیمت یا آمار ساختگی نمی‌شود.
- هر خواندن موجودی کیف پول نیز Genesis مستقل دارد. اسلات موجودی از context همان پاسخ می‌آید. اتصال یک آدرس، به‌تنهایی موجودی را Mainnet معرفی نمی‌کند.
- قیمت SOL از همان منبع بازار استخرهای سولانا می‌آید؛ قیمت بازار، TPS شبکه، نقدینگی استخرهای منتخب و آمادگی اجرای کپی‌ترید برچسب‌های جدا دارند. نقدینگی استخرها TVL پلتفرم معرفی نمی‌شود.
- `/network` مدرک اتصال و لینک مرورگر اصلی سولانا را برای برنامه‌های System، SPL Token، Associated Token، Raydium CPMM و Orca Whirlpool نمایش می‌دهد. بیت `executable` نشان‌دهندهٔ وجود حساب برنامه است؛ حسابرسی یا اجازهٔ خرج‌کردن نیست.

## قرارداد هوشمند

اتصال کیف پول و خواندن موجودی به قرارداد اختصاصی جدید نیاز ندارند. این نسخه به برنامه‌های موجود سولانا متصل می‌شود و کیف پول سایت همچنان فقط آدرس تأییدشده را می‌خواند. کلید خصوصی، قرارداد امانی، آدرس سپردهٔ تازه یا مجوز خرج‌کردن به این مسیر اضافه نشده است. اجرای کپی‌ترید از موتور موجود حساب استفاده می‌کند؛ انتخاب کیف پول مرجع و مجوز حساب کاربر، جداگانه باقی می‌مانند.

یک probe فقط‌خواندنی از endpoint عمومی Solana در جریان توسعه Genesis اصلی و وضعیت قابل‌اجرای هر پنج برنامه را تأیید کرد. این مدرک، استقرار نسخه روی VPS، سلامت RPC اختصاصی کاربر، امضای کیف پول واقعی یا انجام معامله را اثبات نمی‌کند.

## نصب و تکمیل Mainnet

نصب‌کنندهٔ `scripts/deploy-nova-mainnet-luxury.py` باید همراه کل پوشهٔ `scripts` از SHA کامل بررسی‌شده استخراج شود. دستور نصب پین‌شده در پاسخ نهایی ارائه می‌شود. استقرار مستقیم روی VPS از محیط توسعه انجام نشده است.

نصب معمولی با `--release <SHA>`:

1. مخزن، Docker محلی، وضعیت PAPER متوقف، hash واقعی پیکربندی هر دو سرویس، سلامت سایت و پاسخ ۴۱۰ بدون کش مینی‌اپ را بررسی می‌کند.
2. Project ID عمومی Reown را از تصویر وبی که قبلاً روی همین سرور نصب شده دوباره استفاده می‌کند. شناسهٔ تست CI جایگزین تنظیم واقعی نمی‌شود.
3. منبع دقیق commit را جدا استخراج و تصاویر وب و API را می‌سازد. تصویرهای قبلی با شناسهٔ تغییرناپذیر و دستور restore نگه‌داری می‌شوند.
4. فقط API را جایگزین و سلامت آن را بررسی می‌کند؛ سپس وب را جایگزین می‌کند تا nginx آدرس جدید API را resolve کند. پایگاه داده، Redis، ربات، داده‌های حساب و فایل‌های checkout بازسازی نمی‌شوند. migration اجرا نمی‌شود.
5. نسخهٔ واقعی وب و API، بسته‌بودن مینی‌اپ، آمادگی عمومی و ثبات سرویس‌های دیگر را بررسی می‌کند. شکست بررسی، تصویرهای قبلی را برمی‌گرداند؛ تغییر هم‌زمان مدیر یا استقرار جدیدتر باعث توقف بازنویسی می‌شود.

فاز تعویض تصویرها، `.env` یا حالت معامله را تغییر نمی‌دهد. اگر RPC عمومی قابل دسترسی نباشد، نسخهٔ رابط/API می‌تواند نصب شود ولی `SOLANA_MAINNET_VERIFIED=NO` چاپ می‌شود و رابط وضعیت تأییدنشده نشان می‌دهد.

### گزینه‌های صریح عملیاتی

- `--repair-rpc`: اگر RPC اختصاصی تأییدشده و اسکنر سالم موجود نباشند، ابزار موجود `configure-nova-copy-rpc.py` اجرا می‌شود. HTTPS و WSS واقعی provider در ترمینال خصوصی گرفته می‌شوند؛ در چت، مخزن یا خروجی عمومی ثبت نمی‌شوند. ابزار Genesis، blockhash و دریافت واقعی لاگ WebSocket را پیش از تغییر می‌سنجد و در شکست، تنظیم قبلی را بازمی‌گرداند. PAPER و توقف اولیه در این مرحله باقی می‌مانند.
- `--activate-copy`: مرحلهٔ RPC را هم شامل می‌شود و سپس ابزار موجود `enable-live-copy-trading.py --release-bootstrap-stop` را اجرا می‌کند. این گزینه اجازهٔ راه‌اندازی موتور LIVE را می‌دهد؛ فقط توقف اولیهٔ شناخته‌شدهٔ نصب تازه قابل آزادشدن است. توقف دستی/Redis، provider اشتباه، سقف نامعتبر، خاموش‌بودن simulation، تنظیم فعال نامرتبط، کیف پول مرجع فعال یا ویرایش هم‌زمان، جلوی فعال‌سازی را می‌گیرند.
- ابزار هیچ کیف پول، سرمایه یا مرجع کپی جدیدی انتخاب نمی‌کند. سقف‌های محافظه‌کارانهٔ موجود حفظ می‌شوند: حداکثر ۰٫۱ SOL برای هر خرید، ۱۰ تلاش روزانه، ۳ پوزیشن باز و ۱۵۰ bps لغزش، یا سقف پایین‌تر موجود. آماده‌شدن موتور، مدرک انجام تراکنش یا سود نیست.
- بعد از restart یا rollback ابزارهای عملیاتی، nginx فعلی دوباره resolve می‌کند؛ شناسهٔ کانتینر وب عوض نمی‌شود. این مرحله برای جلوگیری از باقی‌ماندن IP قدیمی API ضروری است.

فاز تصاویر و فاز RPC/فعال‌سازی checkpointهای جدا دارند. اگر مرحلهٔ RPC یا کپی کامل نشود، نسخهٔ طراحی نصب‌شده باقی می‌ماند و خطای همان مرحله چاپ می‌شود؛ دستور بازیابی هر ابزار هم جداست. برای restore تصویر API، ابتدا باید تنظیمات به وضعیت متوقف PAPER برگردند. restore روی تصویر API یا وبِ جدیدتر بازنویسی نمی‌کند.

## شواهد آزمون

تست‌های واحد هویت شبکه، دادهٔ موجودی، رد پاسخ ناسازگار و قدیمی، cache هم‌زمان، برنامهٔ مفقود یا غیرقابل اجرا و عدم افشای provider را پوشش می‌دهند. آزمون‌های مرورگر با wallet/API/نمودار کنترل‌شده، Chrome دسکتاپ، اندروید و WebKit آیفون را اجرا می‌کنند؛ دادهٔ این تصاویر آزمون است. آزمون واقعی Compose، hash هر دو سرویس، تعویض image-only و ثبات شناسهٔ سرویس سوم را بررسی می‌کند. CI تصاویر واقعی API و وب را هم می‌سازد. build اجباری API و حذف cache ساخت TypeScript از Docker context جلوی بسته‌بندی تصویر بدون `dist` را می‌گیرند.
