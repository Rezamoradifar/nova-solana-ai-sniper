## Charting (2026-07-14)

"TradingView charts" per the premium-rebuild brief — the real TradingView Advanced Charts library
requires a free license application (external, not self-servable) and isn't vendored in this repo;
see conversation record. Built against **lightweight-charts** (TradingView's own open-source
engine, MIT, npm-installable) behind one isolated component
(`apps/miniapp/src/components/ui/PortfolioChart.tsx`) instead, so swapping to Advanced Charts later
is a small, isolated change once that license is obtained.

## Token fields the Discovery brief asked for that don't exist (2026-07-14)

`Token` (`apps/api/prisma/schema.prisma`) has no **volume** field of any kind, and no **migration
timestamp/flag** — `migrationMonitor.ts` updates `Token.dex` when a pump.fun token migrates and
fires a `token.migrated` WS event, but never persists _when_ or _whether_ a given token migrated as
a queryable field. The Discovery feed shows both as explicit "No data"/"not tracked" UI slots
(`apps/miniapp/src/components/DiscoveryTokenCard.tsx`) rather than omitting them or inferring from
`dex` (which would mislabel a token detected directly on a non-pump.fun DEX). "Risk score" is
likewise not a single stored field — the card composes it honestly from the real flags that do
exist: `aiScore`, `isHoneypotSuspected`, `mintAuthorityRevoked`, `freezeAuthorityRevoked`,
`lpBurnedOrLocked`, `top10HolderPercent`.
